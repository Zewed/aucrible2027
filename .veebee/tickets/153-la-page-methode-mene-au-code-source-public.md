## Ce que l'utilisateur fait
Je vérifie par moi-même que le code du calcul est public.

## Ce qu'il voit
Dans la règle n° 8, le texte « Tu peux tout vérifier. La formule, les notes, les sources et les corrections sont publiques, et le calcul tient en quelques lignes de code. » et un grand bouton « Le code est public sur GitHub » qui s'ouvre dans un nouvel onglet vers github.com/aucrible2027 (maquettes/methode.html).

## C'est fini quand
- [ ] La règle n° 8 dit que la formule, les notes, les sources et les corrections sont publiques et que le calcul tient en quelques lignes de code.
- [ ] Elle affiche un bouton « Le code est public sur GitHub ».
- [ ] Toucher ce bouton ouvre le dépôt public github.com/aucrible2027 dans un nouvel onglet, et la page Méthode reste ouverte.

- Section « Technique » : "Code open source sur GitHub."
